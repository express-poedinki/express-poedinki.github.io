# Экспресс-поединки

Подготовка к экспресс-поединкам КСТ на iPhone: ситуация, фраза, по каждой роли ответная фраза и контрфраза, режим тренировки.

Открыть: https://express-poedinki.github.io/

Данные хранятся только на устройстве (localStorage). Чтобы iOS их не очищала, добавьте страницу на экран «Домой» и время от времени сохраняйте резервную копию из меню «⋯».
